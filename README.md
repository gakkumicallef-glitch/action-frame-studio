# Action Frame Studio

https://www.versacephotography.com this is inspo




"Build a modern, high-energy Sports Photography Portfolio website with a minimalist dark theme. Use the attached images as default placeholder media.




1. Landing / Home Page:




Replicate a dynamic, auto-shifting hero background slider that transitions smoothly between high-impact action photos.

Minimal overlay text with a strong typography logo (e.g., 'NAME SPORTS PHOTOGRAPHY'), a bold tagline, and a direct CTA button ('View Galleries').

Clean top navigation bar containing: Home, Portfolio, About, Contact, and a subtle icon link to /admin login.

Exclude all sponsor logos, brand partnerships, or unnecessary clutter.

2. Portfolio / Gallery System:




A dynamic masonry grid layout categorized by sports (e.g., Football, Basketball, Track, Combat Sports, Athletics).

Clicking an image opens a full-screen, high-resolution lightbox with keyboard arrow navigation.

Include filter tabs at the top of the portfolio section to switch categories instantly.

3. Admin Panel (/admin):




A secure route protected by Supabase Auth for the site owner.

An intuitive upload interface supporting drag-and-drop file selection.

Include automated client-side image compression before uploading (shrinking files under 500 KB).

Allow assigning categories, adding titles/tags, reordering, and deleting images.

4. Responsive Design & Performance:




Fully responsive layout optimized for mobile, tablet, and desktop viewing.

Implement lazy loading for fast page speeds across large image collections."**
